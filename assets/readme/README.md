# README assets

This directory contains repository presentation assets, not application runtime dependencies.

The screenshots were captured from the packaged potato box desktop application against a synthetic QA project. They contain no private user documents or credentials.

- `workspace-graph.png`: linked knowledge graph

- `semantic-search.png`: workspace search results

## Brand artwork

- `potato-box-cover.png`: lossless generated cover master

Show an open modular matte-charcoal box built from a precise five-by-five tile grid, with restrained cobalt, emerald, amber, and ink accents. Extend precise connector lines from the box into document sheets and knowledge nodes on a bright near-white studio field. Use premium editorial 3D materials, high-key lighting, ample negative space, and a 2:1 composition. No words, letters, fake UI, browser frame, watermark, people, literal potatoes, bokeh, purple haze, or excessive glow.
